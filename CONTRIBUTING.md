# Contributing

Use the integrated baseline, create a focused feature branch, and follow [development](docs/development.md). Keep model-family work in its own implementation and configuration directories. Changes to shared data or checkpoint contracts require corresponding regression coverage.

Before opening a pull request, run the documented checks, update affected documentation, and remove generated outputs from the diff. Explain changes to experimental semantics separately from measured performance. See [branch integration](docs/merging.md) for older branches.
